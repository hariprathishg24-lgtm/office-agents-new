# The weekly Improvement Report

Use this whenever you are asked what the office should do differently, or when your weekly
routine fires. It turns the owner's corrections into a short list of changes worth making.

## Before you write
1. Read every file in `Agents Office/feedback/`. Each is one agent: `## Standing rules` are
   corrections already promoted to rules, `## One-offs` are single-task notes.
2. Read `05-Growth/kpis.md` for the numbers, so a recommendation can point at one.
3. Look for **repeats**: the same correction to one agent twice, or the same kind of correction
   (tone, length, missing step) across several agents. One correction to one agent once is not a
   pattern — leave it.

## The shape
```
# Improvement Report — <date>

## What repeated this week
- <the pattern> — <which agents> — <how many times>

## Worth changing
1. <agent or department> · <the change, in one sentence> · <why: the correction it comes from>

## Watching
- <a pattern that appeared once and is not yet worth a rule>

## Numbers
- <the KPI this would move, and where it stands now>
```

## Rules
- Three recommendations at most, ranked. A list of ten is a list nobody acts on.
- Every recommendation quotes the correction it came from, in the owner's own words.
- Never invent a preference the owner did not state.
- **You propose. You never edit another agent's brief, skill or feedback file** — say which file
  should change and what the new line should say, and leave applying it to the owner.
- If nothing repeated, say so in one line and stop. A quiet week is a real answer.
